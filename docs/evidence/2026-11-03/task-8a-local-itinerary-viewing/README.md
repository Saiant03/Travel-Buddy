# Artefacte Task 8A

`report.json`, `final-contrast.json` și `browser-check.mjs` sunt copiile raportului, măsurătorilor de contrast și scriptului folosite la matricea browser finală. Capturile finale selectate includ panoul francez la 320 px și la zoom CSS 200%/640 px, lista desktop/telefon, detaliul românesc și scenariul invalid în engleză.

`baseline-failure-report.json` păstrează prima rulare cu 6 eșecuri B01 din 100 de cazuri, înaintea corecției. `ui-b01-red.log`, `ui-b01-green.log` și `ui-b01-build.log` arată defectul și remedierea focalizată. Jurnalele `domain-tdd.md` și `ui-tdd.md` păstrează limitele RED/GREEN și istoricul de test.

Logurile coordinator sunt copii ale testelor și verificărilor locale. Aceste artefacte nu sunt probe pentru backend sau furnizori reali.

`ui-check-detail-shows-day.log` și `ui-check-restores-stop-focus.log` păstrează RED-uri focale pentru poziția în zi și restaurarea focusului. `ui-check-preserves-fixture-order.log` este GREEN, nu RED; testul ordinii nu certifică TDD separat.
